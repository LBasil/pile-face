# Pile ou face

Un pile ou face transformé en combat contre une IA, en HTML, CSS et JavaScript (Bootstrap 4). Pas de build.

On choisit pile ou face puis on lance la pièce : si on a bon, l'adversaire perd de la vie, sinon c'est nous. Sous 50 % de vie, l'adversaire passe en mode boss (sa barre devient rouge). La partie s'arrête quand l'un des deux tombe à zéro.

## Lancer

Ouvrir `index.html` dans un navigateur.

Démo : https://pile-face.vercel.app/
